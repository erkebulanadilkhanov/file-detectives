FormulaФормула

Finish mission 2 first.Сначала заверши миссию 2.

A .bmp file is not compressed, so you can calculate its size. The picture is 1024 × 600 pixels and every pixel uses 24 bits (24-bit colour). Calculate step by step. A calculator is allowed. Файл .bmp не сжимается, поэтому его размер можно вычислить. Картинка 1024 × 600 пикселей, каждый пиксель занимает 24 бита (24-битный цвет). Считай по шагам. Калькулятором пользоваться можно.

Need a hint? Нужна подсказка?

1 byte = 8 bits, so 24 bits = 3 bytes for every pixel. 1 KB = 1024 bytes. 1 байт = 8 бит, значит 24 бита = 3 байта на каждый пиксель. 1 КБ = 1024 байта.
